## What it is
Two-page web app on Cloudflare Workers + D1 (SQLite). Jay wants **no ChatGPT/OpenAI involvement** — all OpenAI Sites tooling was removed on 2026-11-04; don't reintroduce it.
- `/` — **Control panel** (`app/control-panel.tsx`): add / enable / delete custom headlines ("rotation" or "play next"), RSS feed URL + label, colors, font, font size, scroll speed, OBS setup info, installable as an app (PWA, `public/sw.js`, `app/manifest.ts`).
- `/ticker` — **The ticker** (`app/ticker/ticker.tsx`, styles in `app/globals.css`): the OBS browser source. Lasorda's Card House logo block (`public/brand/lasordas-card-house.png`, light panel + accent trim) + scrolling strip. Items can have a **team panel** (team colors from `lib/teams.ts` — NFL/NBA/MLB/NHL, 124 teams; very dark primaries swap to secondary; team logo = `public/teams/<team key>.png`, all 124 present (200px tall, transparent), see `public/teams/LOGO-FILE-NAMES.txt`; full-size 400px originals in the untracked `team logos/` folder) in the bundled Anton font (`public/fonts`, OFL) and an optional red **tag** pill. Feed stories get the first team they mention (`detectTeam`/`findTeams`) in the summary, else in the RSS headline (summaries often name only the player). Nicknames shared across leagues (Jets, Rangers, Kings, Panthers, Cardinals, Giants, Bucs) resolve by city if named, else by league words in the story (`LEAGUE_HINTS`: goal/power play → NHL, touchdown/quarterback → NFL, …), else no panel. AI team answers go through `teamsNamed` + `mentionsTeam`. **College (major conferences only, Jay's choice):** 79 schools (SEC, Big Ten, Big 12, ACC, Big East, Notre Dame) in `lib/college-teams.ts`, generated with logos (`public/teams/ncaa-<abbr>.png`) by `node scripts/fetch-college-teams.mjs` from ESPN (re-run after realignment; Jay's short names: UM = Miami, UCONN, TAMU via `ABBR_OVERRIDES`). Panels show the short name (`teamLabel`: UM, ASU, UCLA). Matching: "School Nickname" and unique nicknames anywhere; bare school names ("Miami", "Notre Dame") only in college stories (`isCollegeLink`: ESPN link contains /college-football/ etc.), longest name first ("Texas Tech" ≠ "Texas"); shared nicknames (Tigers, Eagles) never mean a college team outside college stories; a college story leads with its college team, other stories with their pro team. Short forms in `COLLEGE_NICKNAMES` / `COLLEGE_SCHOOL_ALIASES` (Irish, Noles, Bama, Mizzou, Pitt…). Scores map college teams by ESPN id (`COLLEGE_BY_ESPN_ID`). The strip polls `/api/headlines` and `/api/settings` every 15s.
- **Rotation (ticker cycle):** news segment → promo → scores segment → next promo → news … Segment length `segment_seconds` (default 180), promo length `promo_seconds` (default 10), 1.4 s "dip" transitions (old scene fades fully out in the first half, new one fades in during the second half, overlapping only near zero, `Leaving` layer; the logo block stays put for strip/text-promo switches, the whole bar fades under a media promo). Custom headlines only appear in the news segment. Scores segment skipped when `scores_enabled` is off or there are no games; with no promos it switches straight between segments. **Live-stream rule: nothing may ever show an error on air** — each source (`/api/headlines`, `/api/settings`, `/api/promos`, `/api/scores`) loads independently and keeps its last good copy; promo files are preloaded and only "ready" ones air (failed ones retried after 5 min); a file that breaks mid-air ends the promo early; render errors are caught by the `Quiet` boundary.
- **Skip ahead** button (Live preview header, needs admin key): POST `/api/advance` bumps `ticker_settings.advance_seq`; every ticker (OBS + preview + phone view) polls GET `/api/advance` every 5 s (was 3 s; changed after the pre-stream audit to save requests) and, when the number goes up, ends the current segment/promo early → normal crossfade to the next part (with no promos/scores it restarts the strip). The first value a ticker sees is only a baseline, so reloading OBS never skips. Presses during a crossfade are ignored. Adds ~720 requests/hour per open ticker; a ticker totals ~1,560/hour (Workers free = 100k/day, so don't leave OBS + preview + phone view open around the clock).
- **Promos** (control panel → Promos): text slides (drawn in the bar, Anton font, @handles in accent color) or uploaded image/GIF/video (PNG/JPG/GIF/WebP/MP4/WebM, ≤25 MB, videos muted; shown in a 60px band centered on the bar, `object-fit: cover`, so a file wider than the source is trimmed evenly on both sides — design it at the OBS source size, 1080×60 for Jay's vertical stream). Shown one at a time in list order; ↑/↓ reorder; 👁 shows one in the live preview now (`ticker-preview:promo`).
- `/phone` — **Phone view** (`app/phone/`): the 1080×1920 vertical stream frame with the ticker (preview mode) in the middle, shrunk to fit the phone screen — what eBay Live viewers see. Opening `/ticker` directly on a phone looks "zoomed in" because it draws at the phone's own ~390px width without the stream's downscale. Linked from the control panel header ("Phone view").
- `/ticker?preview=1` — **Preview mode** of the same ticker. Never consumes "play next" headlines. When framed by the control panel it takes unsaved settings via `postMessage` (`ticker-preview:settings`, `ticker-preview:refresh`; it sends `ticker-preview:ready`, same-origin only). The control panel's Live preview (`PreviewStage`) shows it as a scaled stream frame (middle band crop), Vertical 1080×1920 (default, Jay streams vertical on eBay Live) or Horizontal 1920×1080, choice remembered per browser with an "unsaved changes" badge.

## API (`app/api/`)
- **Multiple feeds (2026-11-05, Jay's choice):** `ticker_settings.feed_url` holds one feed address per line (`lib/feeds.ts`; a single address still works). Each feed is fetched/cached separately (same 15-min cache + last-good copy); when several are set, each adds its newest 12 stories (`PER_FEED_WHEN_MIXED`; one feed alone: 40), mixed by taking turns between feeds (sports spread out) with the same story from two sites kept once (`sameStory`). One feed failing doesn't stop the others; `/api/headlines` returns `feeds` (per-feed stories/error) and the control panel shows it per row. `RECOMMENDED_FEEDS` ("Use recommended mix" button) = the cleanest free feed per sport, tested against `lib/news-filter.ts` on 2026-11-05: NFL NBC Pro Football Talk (3% features), NBA Yahoo (32%), MLB Yahoo (20%), NHL NBC (0%), college football Yahoo (32%), college basketball ESPN (23%); ESPN top news was 68%. The AI reads **headline + summary** (`aiText`, prompt v9): NBC/Yahoo summaries often omit who the story is about. Team detection ignores a team named right after vs./versus/against/over/past/beat/defeated (the opponent), and the AI TEAM must be the subject's own team, never the opponent.
- `headlines/route.ts` — fetches up to 40 RSS/Atom items (default ESPN top news `https://www.espn.com/espn/rss/news`). Each item shows the story **summary** (`<description>`/`<summary>`) when usable (≥40 chars, no links, not just the title), else the headline; long ones cut to their first sentence (abbreviation-aware), then to ~150 chars at a word boundary. Google News descriptions are only links, so it falls back to headlines there. Feed is cached in memory per isolate: re-fetched at most every 15 min (Jay's choice), retried 2 min after a failure, and the last good copy is served for up to 12 h if the feed site refuses (Google returns 503 to frequent requests from Cloudflare). Response includes `feedError`, `feedStale`, `feedAgeSeconds`, `ai` stats. **AI short lines** (`lib/ai-summary.ts`, Workers AI, binding `AI`; models tried in order `AI_MODELS` = llama-3.3-70b-instruct-fp8-fast → mistral-small-3.1-24b → gemma-3-12b, auto-skipping retired ones (llama-3.1-8b-instruct was retired 2026-05-30; no OpenAI models)): **Panel team never opens the line (prompt v7, Jay's rule):** the AI leads with the player or event ("Jacoby Brissett being traded to Ravens" under a Cardinals panel). `startsWithTeam` checks it; if the line still opens with the panel team the AI is asked once more to reword, and if that retry fails a safety check the first line airs. Never strip names mechanically (that gave fragments like "Lose Lamar Jackson", v3). AI TEAM may now be a major college team; the AI step gets the college-story flag too (prompt v8), so "Hurricanes" in a college story = UM, never Carolina's NHL team, and a college story never keeps a pro panel. Teams without a panel (LIV Golf, golfers, leagues…) must be named in the line: if not, one retry asks for it. Prompt also says keep the exact meaning (a line once read "lack of defense" for "teammates didn't defend him"); this is guidance, not a guarantee. each new story is rewritten once into a ≤70-char line + main team, stored in D1 `ai_lines` (key = story id + text hash, pruned after 3 days); max 3 new stories per request, 8s timeout, 5-min pause after an AI error. Safety checks (`checkLine`): ≤80 chars (`AI_MAX_LENGTH`), every number and every capitalized name must appear in the original story, no chatbot phrasing; failures air the trimmed original, but only if it is ≤120 chars (`ORIGINAL_MAX`); longer ones are skipped until the AI shortens them (so with the AI off/down the strip gets sparse). AI team only used if the story mentions it. Toggle: `ticker_settings.ai_summaries` (control panel → News feed → AI short lines). Local `npm run dev` skips the AI (remote-only binding; `TICKER_REMOTE_AI=1` to use it, needs wrangler login). "Play next" custom headlines go first and are flipped to "rotation" once the ticker loads them (`?consumeNext=1`). One rotation custom headline is inserted after every 4 feed items. If the feed fails, only custom items show.
- `settings/route.ts` — GET/PATCH appearance + feed + rotation settings (validated: hex colors, font whitelist, size 18–36, speed 30–180, public feed URL only, segment 30–900 s, promo 3–60 s).
- `scores/route.ts` — game scores (`lib/scores.ts`) from ESPN's public scoreboard JSON (`site.api.espn.com/apis/site/v2/sports/<sport>/<league>/scoreboard`; unofficial, so everything fails quietly). NFL, NBA, MLB, NHL, college football, men's college basketball. Grouped by sport (`groupScores`: each league appears once; sports with a live game first, then NFL, NBA, MLB, NHL, college; max 15 per sport); within a sport live first, then finals (started ≤16 h ago), then upcoming (≤18 h ahead, times in PT). College: only games with a ranked team, except live games (max 15). Per-league fetch every 60 s, 6 s timeout, last good copy kept 20 min. Pro teams map to our keys by abbreviation (`ABBR_FIX` for ESPN's different codes) or nickname → our colors + logos; college uses ESPN's logo URL. Never returns an error (empty list instead).
- `promos/route.ts` (GET list, POST text JSON or multipart `file` upload, PATCH `{order}`), `promos/[id]/route.ts` (PATCH enabled/text, DELETE incl. R2 file), `promos/media/[key]/route.ts` (serves R2 files, byte ranges, immutable cache). Uploads need the R2 binding `MEDIA` (bucket `lasorda-ticker-media`); without it text promos still work and uploads return a plain message.
- `custom/route.ts`, `custom/[id]/route.ts` — list/add/update/delete custom headlines.
- Writes require header `X-Admin-Key` == secret `ADMIN_TOKEN`. With no secret set, the key `local` works **only on localhost**; a deployed site without the secret is locked. See `lib/admin-auth.ts`.

## Data
- D1 binding `DB` (configured in `wrangler.jsonc`, database `lasorda-ticker-db`). Tables: `custom_headlines` (incl. optional `team` key + `tag`), `ticker_settings` (single row id=1, incl. `ai_summaries`, `segment_seconds`, `promo_seconds`, `scores_enabled`), `ai_lines` (AI ticker line cache), `promos` (kind text/image/video, text, media_key, enabled, position).
- R2 binding `MEDIA` (bucket `lasorda-ticker-media`) for uploaded promo files. R2 must be turned on once in the Cloudflare dashboard (free 10 GB, asks for a card); the deploy scripts create the bucket if missing. Local dev emulates R2 automatically.
- Schema in `db/schema.ts`; migrations in `drizzle/` (0000–0007). `npm run db:generate` after schema changes, then `npm run db:migrate:local` / `db:migrate:remote`.
